# My Task List

## Author

Ashwin Antony (Ash)

## Description

My Task List is a simple interactive task management web application created using HTML, CSS, and JavaScript.

The application allows users to:

* Enter a task
* Choose a Low, Medium, or High priority
* Add the task to the page
* Mark tasks as completed
* Delete tasks

Tasks are stored only while the page is open and are not saved after the page is refreshed.

## How to Run the Program

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. You can also use the Live Server extension in Visual Studio Code to run the page.
